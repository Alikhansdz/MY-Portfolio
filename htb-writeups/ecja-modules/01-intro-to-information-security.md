# Module 1 — Introduction to Information Security

## What This Module Covers
Introduction to cybersecurity fundamentals including core
concepts, threat landscape, and how organizations approach
security.

## What I Learned

### CIA Triad
- Confidentiality — only authorized people access data
- Integrity — data is not altered or tampered with
- Availability — systems accessible when needed

### Threat Actors
- Script kiddies — low skill, use existing tools
- Hacktivists — politically motivated
- Nation states — government sponsored, most advanced
- Insider threats — employees with malicious intent

### Security Controls
- Preventive — stop attacks before they happen
- Detective — identify attacks as they happen
- Corrective — fix damage after attack

### NIST Framework
Five functions: Identify, Protect, Detect, Respond, Recover

## Key Takeaway
Every security decision maps back to CIA triad.
Understanding what's being protected and from whom
is the foundation of all security work.
