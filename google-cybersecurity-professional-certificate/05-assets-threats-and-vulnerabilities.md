# Course 5 — Assets, Threats & Vulnerabilities

## Overview
How organizations classify assets, identify threats, and
analyze vulnerabilities — the foundation of risk-based security.

## Key Concepts Learned
- Asset classification — confidential, internal, public
- Threat modeling — identifying attack vectors
- Vulnerability assessment process
- MITRE ATT&CK framework — tactics and techniques
- Social engineering attacks
- Malware types — virus, worm, trojan, ransomware, spyware
- Web-based exploits overview
- Cryptography basics

## MITRE ATT&CK Tactics
- Reconnaissance
- Resource Development
- Initial Access
- Execution
- Persistence
- Privilege Escalation
- Defense Evasion
- Credential Access
- Discovery
- Lateral Movement
- Collection
- Exfiltration
- Impact

## SOC Relevance
MITRE ATT&CK is the universal language of SOC work. Every
alert is mapped to a MITRE technique. Knowing the framework
deeply separates good SOC analysts from average ones.
