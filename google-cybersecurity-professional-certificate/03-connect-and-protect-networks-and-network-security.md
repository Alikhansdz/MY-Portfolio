# Course 3 — Connect and Protect: Networks & Network Security

## Overview
Deep dive into how networks are structured and secured,
covering protocols, architecture, and common attack techniques.

## Key Concepts Learned
- TCP/IP model in depth
- Network protocols — HTTP, HTTPS, DNS, DHCP, ARP
- Network architecture — routers, switches, firewalls
- VPN and network segmentation
- Cloud networking basics
- Common network attacks — DDoS, MITM, packet sniffing
- System hardening techniques

## Key Concepts — Network Attacks
- Denial of Service — overwhelming resources
- Man in the Middle — intercepting communications
- Packet Sniffing — capturing unencrypted traffic
- IP Spoofing — faking source IP addresses

## SOC Relevance
Network security is the most fundamental SOC domain. Every
intrusion involves network traffic. Understanding how attacks
traverse networks is essential for detection.
