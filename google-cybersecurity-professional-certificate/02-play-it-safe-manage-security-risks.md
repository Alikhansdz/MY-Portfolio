# Course 2 — Play It Safe: Manage Security Risks

## Overview
How organizations identify, assess, and manage security risks
using frameworks, controls, and playbooks.

## Key Concepts Learned
- Security frameworks and controls in depth
- OWASP security principles
- Security audits — purpose and process
- Incident response playbooks
- SIEM tools introduction — Splunk and Chronicle

## Key Tools Introduced
- Splunk — log aggregation and analysis
- Chronicle — Google's cloud SIEM
- Playbooks — structured incident response guides

## SOC Relevance
Playbooks are the backbone of SOC operations. Every alert has
a playbook. Understanding how to follow and eventually write
playbooks is a core junior SOC skill.
